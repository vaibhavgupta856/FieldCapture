# Sample job records

Place **three** real job records here, named `walk_01.json`, `walk_02.json`, `walk_03.json`.
Each must be exported from a completed walk-through of the submitted build using the
app's **Export jobs** button, and each must include at least one nameplate, one damage
capture and one note. Copy the JSON verbatim; do not edit fields by hand.

No sample files are committed in this scaffold because fabricating them would invalidate
the evaluation.
